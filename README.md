# 🎮 Linux Quest: Terminal Escape

**Linux Quest: Terminal Escape** is an interactive, cyberpunk-themed Linux command-line learning game built with Python and Streamlit.

Explore simulated Linux environments, complete missions, earn experience points, and escape the server before time runs out.

## ✨ Features

- 🎯 10 command-based Linux missions
- 💻 Interactive simulated terminal
- 🌌 Cyberpunk-inspired interface
- ⚡ Experience points (XP) and mission progression
- ❤️ Lives system
- ⏱️ Countdown timer
- 💡 Mission hints
- 🏆 Victory and game-over states
- 🎵 Background cyberpunk soundtrack
- 🔁 Loop-enabled music player
- 🔄 Restartable gameplay

## 🛠️ Technologies

- Python
- Streamlit
- Git and GitHub

## 📋 Requirements

- Python 3.10 or later
- pip
- Git (optional, for cloning the repository)
